# NERVA 核热推进试验控制台

一个无需构建、无需安装依赖的 HTML 可玩演示。冷战与阿波罗时代的仪表语言：橄榄灰金属面板、模拟表针、绿磷 CRT、紧凑状态灯矩阵与机械开关。

现在支持原有沙盒与两个飞船变轨挑战，顶部可切换模式。

## 打开

直接用浏览器打开 **`NERVA.html`** 即可运行。这是可独立复制、分享的单文件版本。开发入口为 `index.html`，也可运行 `npm start`，访问终端显示的 `http://127.0.0.1:4173`。界面和模拟不依赖网络；在线时可加载 Google Fonts，离线时使用系统字体。修改源文件后，运行 `npm run standalone` 更新单文件版本。

## 玩法

- 初始为液氢、1.40 m 堆芯、60% 功率、70% 主阀开度的稳定试车。
- 调节反应堆功率、主阀和推进剂泵，观察热惯性、流量冷却和喷管性能。
- 正常停机，等待热功率低于 5 MW 后，可切换液氢/水和 0.80–2.40 m 堆芯直径。额定功率、额定流量、发动机质量随尺寸变化。
- MFD 有系统剖面、热力回路、推进性能、120 秒遥测趋势、故障诊断五页。
- 可注入泵失速、冷却失效、管路泄漏、主阀卡滞、传感器漂移五类故障。告警确认停止闪烁；修复故障解除指示。
- 自动保护在超温、超压、供液不足和推进剂耗尽时紧急停堆。关闭保护后，过热会累积堆芯损伤。SCRAM 后仍有余热，需要保持冷却。
- 空格暂停，1–5 或 F1–F5 切换 MFD，? 打开手册，Esc 关闭弹窗。按钮支持键盘操作。
- 试验支持 1×、2×、5×速度。重置后回到冷态待机。

## 挑战小游戏

点击「挑战模式」，选择任务、推进剂和堆芯直径，装载后从零功率冷态待机开始。推进剂在本局全程锁定；首次点火前可调整堆芯直径，点火后尺寸锁定。冷态推力、功率、压力、流量、加速度与 Δv 均为零；温度保持物理单位，冷机为 293 K（约 20°C）。

冷启动步骤：打开推进剂泵和冷却回路，将主阀设为约 70%、反应堆功率设为约 60%，再点击「启动试车」。挑战支持 1×、2×、5×、10×、25×模拟速度。首次点火前不计时，首次点火后包括滑行和冷却在内的全部模拟时间均计入任务用时；暂停冻结模拟与任务计时。

飞船干重＋载荷为 **10,000 kg，包含发动机**，不再额外叠加发动机质量。液氢初装 **10,000 kg**（起飞总质量 20 吨），水初装 **30,000 kg**（总质量 40 吨）。用实时推力除以变化的总质量得到加速度，以 0.05 秒或更短子步积分 Δv 和飞行距离。航行是无引力的一维真空变轨；所有推力均沿前进方向，不能反向制动。泄漏的推进剂计入质量消耗，泄漏部分不产生推力。

### 任务与计分

1. **无限加速**：原始分 = 最终 Δv（m/s）× 10。尽可能把推进剂转换为速度增量。
2. **精确入轨注入**：每局随机产生 2,750–2,850 m/s 的整数目标，仅在装载新任务时抽取。原始分 = 10,000 + 剩余推进剂（kg），不加 Δv 分。误差系数 = `max(0, 1 − |最终Δv − 目标Δv| × 0.01)`；每 1 m/s 绝对误差扣 1%，100 m/s 及以上误差得分归零。

两种任务共同应用：

- 时间系数 = `max(0, 1 − 任务秒数 / 10000)`，每 100 秒扣 1%，按连续比例计算。
- 耐久系数 = `1 − (100 − 剩余耐久百分比) × 0.005`，每损失 10% 耐久扣 5%，按连续比例计算。
- 最终分 = `floor(原始分 × 误差系数 × 时间系数 × 耐久系数)`，无限加速的误差系数固定为 1。分数最低为 0。

例如无限加速获得 1,000 m/s、用时 200 秒、剩余耐久 80%：`10000 × 0.98 × 0.9 = 8820 分`。结算报告列出各项加分、扣分、系数和最终成绩。

### 停机与结算

试车台新增「结算本次变轨」。**实际堆芯温度必须严格低于 800 K**，不能在准备阶段直接结算。正常停机后保持闭式冷却回路运行；关闭主阀可以减少燃料消耗，冷却回路仍可散去余热。停机前和供液惯性期间仍可能增加 Δv，精确任务需提前预留。

推进剂耗尽或堆芯损毁后进入自动冷却结算阶段，即使关闭自动保护，也不会继续燃烧空油箱；达到低于 800 K 的温度条件后自动结算。关闭或损坏冷却回路会延长冷却时间。结算后冻结本局，支持复盘 MFD、重看报告或重新挑战。重试重新装载完整推进剂与耐久，并为精确任务生成新目标。

## 模型范围

使用确定性、集总热容的简化演示模型：功率与流量有响应延迟，温度由输入热量、推进剂有效比热与流量共同决定，水模式计入简化汽化能耗，喷管采用理想气体膨胀近似，推力由质量流量与排气速度计算。模型保留质量消耗、停机余热、传感器独立偏差和保护联锁。闭式冷却回路使用简化余热散热模型，耗尽储罐后仍可冷却。实际供液受到剩余推进剂约束，不会在空罐后凭空产生推力。

这是概念和界面演示，**不用于工程计算或真实设备控制**。未模拟中子学、燃料材料或高温化学；水模式为假设性演示。NTR 在此指核热火箭，区别于将核热先转为电能的核电推进。

背景参考：[NASA Space Nuclear Propulsion](https://www.nasa.gov/space-technology-mission-directorate/tdm/space-nuclear-propulsion/)、[NASA NTRS: NTP overview](https://ntrs.nasa.gov/citations/20120003776)。

## 验证

`npm test` 运行模拟模型测试；`npm run check` 检查 JavaScript 语法。`simulation.js` 可独立通过 CommonJS 加载，不依赖浏览器。

文件：`index.html` 页面、`style.css` 外观、`simulation.js` 发动机模型、`challenge.js` 飞船与计分模型、`app.js` 交互与仪表绘制、`server.cjs` 本地静态预览。
